Not really. I would expect the other way round as properties of an object are accessed directly and not retrieved from a map by key. There might be some drawback in using`@NamedVariant` in similar as I'm afraid they will create both — a map and an object from the map.

I would prefer clarity and maintainability over premature optimization. There is nothing worse than when you don't know what values you can actually pass using the map.
