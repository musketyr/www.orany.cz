I'm definitely not saying write everything in Java but suggest to think twice when you create a new source file.

Are you creating an interface? There is 100% chance that writing interface in Java will give you better features and experience than writing the interface in Groovy (as of Java 8 and Groovy 2.x).

Are you creating an enum? If it is just a bare enumeration there is no need to write it in Groovy.

I think you can find many other situations where you can be as effective in Java as in Groovy. One day, when you hire new developers, they will be grateful to you as usually they will be old good Java developers and finding some Java code will make them more comfortable in their new jobs.
